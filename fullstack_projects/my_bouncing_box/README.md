# Welcome to My Bouncing Box
***

## Task
The goal of this project is to recreate the classic Windows DVD/Bouncing Screensaver using JavaScript.A square moves diagonally across the browser window and changes direction whenever it hits one of the screen borders.The HTML structure must remain unchanged, and all movement is handled with JavaScript.


## Description
I solved this project by using JavaScript to control the position of the box.

- Selected the box using `document.getElementById()`.
- Used the `left` and `top` CSS properties to move the box.
- Updated its position continuously with `setInterval()`.
- Kept track of the horizontal and vertical directions.
- Reversed the direction whenever the box touched the window borders.


## Installation
The goal of this project is to recreate the classic Windows DVD/Bouncing Screensaver using JavaScript. A square moves diagonally across the browser window and changes direction whenever it hits the screen borders. The HTML structure must remain unchanged, and all movement is handled using JavaScript.

Simply clone the repository or download the project files and open `index.html` in any modern web browser.


## Usage
Open the project by launching the `index.html` file in your browser.

The blue box will start moving diagonally and bounce off the edges of the browser window.
