# Welcome to My Roman Numerals Converter Fs
***

## Task
The task is to create a function that converts normal numbers into Roman numerals.
For example:
14 → XIV
79 → LXXIX
845 → DCCCXLV
2022 → MMXXII
The challenge is to find the correct Roman numeral for each part of the number.
## Description
I solved the problem by creating an object with numbers and their Roman numeral values.I also created an array with the values
from biggest to smallest.The program checks each value and adds the correct Roman numeral to the result. It continues until
the number becomes 0.

## Installation
No special installation is needed for this project. You only need JavaScript to run the function. Download or clone the project,
open the JavaScript file, and run the function with a number.

## Usage
Call the function with a number:

my_roman_numerals_converter(845);
It returns:
DCCCXLV
